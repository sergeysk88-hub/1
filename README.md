# Tsyrena · cosmetolog — сайт косметолога

Одностраничный сайт (эстетика + инъекции) в одном файле `index.html`: HTML, CSS и JS внутри, без сборки и зависимостей.

**Запуск:** откройте `index.html` в браузере.
**Публикация:** загрузите файл на любой хостинг (GitHub Pages, Netlify, Tilda «Zero-блок», обычный хостинг).

## Что заменить (в коде помечено ✏️)

1. **Контакты** — объект `CONFIG` в начале `<script>` внизу файла: WhatsApp, Telegram, телефон, адрес, часы. Ссылки обновятся по всему сайту.
2. **Фото** — у блока с классом `photo` добавьте `style="--img:url('photo.jpg')"`, заглушка исчезнет автоматически.
3. **Тексты, цены, длительность, цифры** в блоке «Обо мне».
4. **Отзывы** — только реальные, с согласия клиенток.
5. **Фото «до/после»** — только с письменного согласия пациентов.
6. **Реквизиты, номер лицензии, политика конфиденциальности** — в подвале.

Форма записи не требует сервера: она собирает заявку и открывает WhatsApp или Telegram с готовым текстом.
