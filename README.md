# Tsyrena · cosmetolog — сайт косметолога

Одностраничный сайт (эстетика + инъекции) в одном файле `index.html`: HTML, CSS и JS внутри, без сборки и зависимостей.

**Запуск:** откройте `index.html` в браузере.
**Публикация:** загрузите на хостинг `index.html` и фото. Вместе с ними выложите файл заголовков для своей площадки (см. «Безопасность»).

## Что заменить (в коде помечено ✏️)

1. **Контакты** — блок `site-config` внизу `index.html` (формат JSON):
   ```json
   "whatsapp": "79161234567",
   "telegram": "tsyrena_cosmetolog",
   "phone": "79161234567",
   "instagram": "tsyrena.cosmetolog",
   "avito": "https://www.avito.ru/user/…/profile",
   ```
   Номер на сайте сам отобразится как `+7 (916) 123-45-67`. Пока поле пустое или заполнено неверно, его кнопки скрыты, а заявки по этому каналу не отправляются. Если не заполнен ни WhatsApp, ни Telegram, форма записи выключается и предлагает позвонить. При локальном просмотре вверху появится жёлтая подсказка (в том числе об ошибке в JSON), посетители сайта её не увидят. Не используйте в значениях знак `<`.
2. **Фото** — у блока с классом `photo` добавьте `style="--img:url('photo.jpg')"`, заглушка исчезнет автоматически. Сейчас на главном экране и в «Обо мне» стоят временные кадры из баннера Авито (`img/tsyrena.jpg`, `img/about.jpg`) — замените их оригиналами фотосессии с теми же именами. Фото кладите рядом с `index.html`: ссылки на чужие сайты (VK, Instagram) заблокирует политика безопасности. Перед загрузкой удалите из фото EXIF с геолокацией.
3. **Тексты, цены, длительность, цифры** в блоке «Обо мне».
4. **Отзывы** — только реальные, с согласия клиенток, или с Авито (см. «Авито: привязка профиля»).
5. **Фото «до/после»** — только с письменного согласия пациентов.
6. **Реквизиты, номер лицензии, политика конфиденциальности** (`<dialog id="privacy">`), а также адрес и телефон в JSON-LD в `<head>`.

Форма записи не требует сервера: она собирает заявку и открывает WhatsApp или Telegram с готовым текстом. Если браузер заблокировал открытие, на экране появится кнопка, чтобы открыть мессенджер вручную.

## Авито: привязка профиля

Утилита `tools/avito-sync.mjs` переносит профиль Авито на сайт: берёт данные из официального API Авито и вписывает их прямо в `index.html`. Браузер посетителя к Авито не обращается, ключи на сайт не попадают, политика безопасности остаётся строгой.

| Что | Откуда | Куда на сайте |
|---|---|---|
| Отзывы (до 30, с оценкой от 4 и с текстом) и ваши ответы на них | `/ratings/v1/reviews` | блок «Отзывы», между метками `<!-- avito:reviews -->` |
| Рейтинг и число отзывов | `/ratings/v1/info` | под отзывами, между метками `<!-- avito:rating -->` |
| Все активные объявления с ценами и ссылками | `/core/v1/items` | раскрывающийся список «Все услуги и цены на Авито» под карточками услуг, метки `<!-- avito:items -->` |
| Цены в карточках услуг | те же объявления | ценники с атрибутом `data-avito-item` (привязываются сами) |
| Телефон, ссылка на профиль, адрес | `/core/v1/accounts/self`, адрес первого объявления | `phone`, `avito`, `address` в `site-config`, а также телефон, адрес и `sameAs` в микроразметке JSON-LD |

Чего нет в API Авито и что ведётся на сайте вручную: описания и фото объявлений, часы работы, фото из отзывов (политика безопасности не пускает картинки с чужих сайтов).

**1. Ключи.** В кабинете Авито откройте [раздел API](https://www.avito.ru/professionals/api) и получите `client_id` и `client_secret` (для некоторых аккаунтов доступ к API требует тарифа, это видно в кабинете). Создайте рядом с `index.html` файл `.env`:
```
AVITO_CLIENT_ID=ваш_client_id
AVITO_CLIENT_SECRET=ваш_client_secret
```
Файл указан в `.gitignore`. Не загружайте его на хостинг и никому не пересылайте.

**2. Пробный запуск** ничего не меняет и показывает, что изменится:
```
node --env-file=.env tools/avito-sync.mjs --dry-run
```

**3. Обновление.** `node --env-file=.env tools/avito-sync.mjs` (нужен Node.js 20.6+). После этого выложите `index.html` на хостинг. Если какой-то раздел API не ответил, соответствующий блок сайта остаётся прежним.

**Как привязываются цены.** Карточка услуги сама привязывается к объявлению с тем же названием, без учёта регистра, порядка слов и окончаний: «Химические пилинги» ↔ «Пилинг химический», «Контурная пластика губ» ↔ «Контурная пластика губ гиалуроном». Точное совпадение важнее частичного. Карточка не привязывается, а утилита просит выбрать вручную, если:
- подходят несколько объявлений («Мезотерапия» ↔ «Мезотерапия лица» и «Мезотерапия волос»);
- то же объявление подходит и другой карточке;
- это программа из нескольких процедур («Сияние к событию», «Anti-age», «Чистая кожа»);
- цена указана за единицу («от 350 ₽ / ед.»), ведь в объявлении цена обычно за всю процедуру.

Карточки, для которых объявление не нашлось, утилита перечисляет в выводе. Привязка записывается в ценник, её видно и можно исправить:
```html
<p class="price" data-avito-item="4123456789"><small>от</small> 14 000 ₽</p>
```
Вместо номера можно вставить ссылку на объявление, а `data-avito-item="нет"` запрещает привязку карточки. Меняется только число перед «₽», «от» и «/ ед.» остаются. Если объявление снято или в нём нет цены, ценник не меняется и утилита об этом предупредит.

**Автоматически раз в день.** Если сайт публикуется из GitHub (GitHub Pages, Netlify, Cloudflare Pages), добавьте в репозитории секреты `AVITO_CLIENT_ID` и `AVITO_CLIENT_SECRET` (Settings → Secrets and variables → Actions). Workflow `.github/workflows/avito-sync.yml` будет каждое утро запускать синхронизацию и коммитить `index.html`, если что-то изменилось. Он работает из основной ветки репозитория. Запустить вручную можно на вкладке Actions. Если Авито отклоняет запросы с серверов GitHub, запускайте утилиту со своего компьютера.

**Настройки** (✏️ в начале `tools/avito-sync.mjs`): число отзывов, минимальная оценка (`MIN_SCORE = 1` покажет все отзывы), минимальная длина текста, показ ответов и подпись к ним, автопривязка карточек (`AUTO_LINK`). Контакты, вписанные вручную в `site-config` и JSON-LD, утилита не перезаписывает. Она заменяет только пустые поля, заглушки вроде «ул. Примерная» и ссылку на отдельное объявление (её — ссылкой на профиль). Телефон и адрес в JSON-LD берутся те же, что в `site-config`. Чтобы данные с Авито всегда имели приоритет, поставьте `OVERWRITE_CONTACTS = true`. Из имени автора отзыва публикуется только первое слово имени из профиля Авито, обычно это имя без фамилии.

Всё, что стоит между метками `<!-- avito:… -->`, перезаписывается при каждом запуске, поэтому правки вручную вносите вне меток. Пока синхронизация не запускалась, в блоке отзывов стоят примеры, замените их или запустите утилиту. Если подходящих отзывов на Авито нет, утилита убирает примеры и скрывает ленту, а рейтинг и кнопка «Все отзывы на Авито» остаются.

## Безопасность

- **Content-Security-Policy** (в `<meta>`): браузер выполняет только два встроенных скрипта с атрибутом `data-csp`, сверяя их sha256-хеши. Посторонний код не запустится. Форма не может «отправиться» в адресную строку. Если меняете код этих скриптов (кроме `site-config`), пересчитайте хеши:
  ```
  node tools/update-csp.mjs
  ```
  Утилита откажется работать, если найдёт в файле посторонний `<script>` (например, случайно вставленный вместе с отзывом) или сломанный JSON.
- **Заголовки сервера** защищают от встраивания сайта во фрейм (кликджекинг), задают HSTS и другое. Выберите файл под свой хостинг:
  - Netlify / Cloudflare Pages: `_headers`
  - Apache и обычный хостинг: `.htaccess` (заодно закрывает доступ к `.git`, README и `tools/`, но пропускает `/.well-known/` для SSL-сертификата)
  - nginx: `nginx.conf.example`
  - GitHub Pages свои заголовки не поддерживает: там работает только защита из `<meta>`.
- **Форма** очищает ввод от невидимых и управляющих символов, ограничивает длину и проверяет телефон. Сайт ничего не хранит и не отправляет на свой сервер: после нажатия «Отправить заявку» текст передаётся только выбранному мессенджеру (это описано в политике).
- **Google Fonts** передаёт IP посетителей Google (это упомянуто в политике). Чтобы этого избежать, разместите шрифты на своём хостинге.
