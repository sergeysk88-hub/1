# Tsyrena · cosmetolog — сайт косметолога

Одностраничный сайт (эстетика + инъекции) в одном файле `index.html`: HTML, CSS и JS внутри, без сборки и зависимостей.

**Запуск:** откройте `index.html` в браузере.
**Публикация:** загрузите на хостинг `index.html` и фото. Вместе с ними выложите файл заголовков для своей площадки (см. «Безопасность»).

## Что заменить (в коде помечено ✏️)

1. **Контакты** — блок `site-config` внизу `index.html` (формат JSON):
   ```json
   "whatsapp": "79161234567",
   "telegram": "tsyrena_cosmetolog",
   "phone": "79161234567",
   "instagram": "tsyrena.cosmetolog",
   ```
   Номер на сайте сам отобразится как `+7 (916) 123-45-67`. Пока поле пустое или заполнено неверно, его кнопки скрыты, а заявки по этому каналу не отправляются. Если не заполнен ни WhatsApp, ни Telegram, форма записи выключается и предлагает позвонить. При локальном просмотре вверху появится жёлтая подсказка (в том числе об ошибке в JSON), посетители сайта её не увидят. Не используйте в значениях знак `<`.
2. **Фото** — у блока с классом `photo` добавьте `style="--img:url('photo.jpg')"`, заглушка исчезнет автоматически. Фото кладите рядом с `index.html`: ссылки на чужие сайты (VK, Instagram) заблокирует политика безопасности. Перед загрузкой удалите из фото EXIF с геолокацией.
3. **Тексты, цены, длительность, цифры** в блоке «Обо мне».
4. **Отзывы** — только реальные, с согласия клиенток.
5. **Фото «до/после»** — только с письменного согласия пациентов.
6. **Реквизиты, номер лицензии, политика конфиденциальности** (`<dialog id="privacy">`), а также адрес и телефон в JSON-LD в `<head>`.

Форма записи не требует сервера: она собирает заявку и открывает WhatsApp или Telegram с готовым текстом. Если браузер заблокировал открытие, на экране появится кнопка, чтобы открыть мессенджер вручную.

## Безопасность

- **Content-Security-Policy** (в `<meta>`): браузер выполняет только два встроенных скрипта с атрибутом `data-csp`, сверяя их sha256-хеши. Посторонний код не запустится. Форма не может «отправиться» в адресную строку. Если меняете код этих скриптов (кроме `site-config`), пересчитайте хеши:
  ```
  node tools/update-csp.mjs
  ```
  Утилита откажется работать, если найдёт в файле посторонний `<script>` (например, случайно вставленный вместе с отзывом) или сломанный JSON.
- **Заголовки сервера** защищают от встраивания сайта во фрейм (кликджекинг), задают HSTS и другое. Выберите файл под свой хостинг:
  - Netlify / Cloudflare Pages: `_headers`
  - Apache и обычный хостинг: `.htaccess` (заодно закрывает доступ к `.git`, README и `tools/`, но пропускает `/.well-known/` для SSL-сертификата)
  - nginx: `nginx.conf.example`
  - GitHub Pages свои заголовки не поддерживает: там работает только защита из `<meta>`.
- **Форма** очищает ввод от невидимых и управляющих символов, ограничивает длину и проверяет телефон. Сайт ничего не хранит и не отправляет на свой сервер: после нажатия «Отправить заявку» текст передаётся только выбранному мессенджеру (это описано в политике).
- **Google Fonts** передаёт IP посетителей Google (это упомянуто в политике). Чтобы этого избежать, разместите шрифты на своём хостинге.
